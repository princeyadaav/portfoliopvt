# Prince Yadav — Portfolio

A responsive React + TypeScript portfolio for showcasing data science, machine learning, and application development work.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`, then deploy the generated `dist` directory to Vercel. Vercel detects Vite automatically when the repository is connected.

## Customize

- Edit personal details and external URLs in `src/config.ts`.
- The resume download uses `public/Prince_Yadav_Data-analytics_Resume.pdf`; replace that file and update `profile.resume` when the resume changes.
- Edit project cards, categories, statuses, and feature lists in `src/data.ts`.
- Missing links are intentionally shown as configuration placeholders and are not fabricated.
- The contact action is a `mailto:` link only after an email is configured; add a secure backend before adding a form or email service.
